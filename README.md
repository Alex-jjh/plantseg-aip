# AIP304 Coursework 2 — Option 1: plant-disease recognition in the wild

CNN classification of 43 host–disease classes (9 hosts) from single RGB photographs, PlantSeg v7 subset.

**Deliverable notebook:** [`notebooks/AIP304_CW2_Option1.ipynb`](notebooks/AIP304_CW2_Option1.ipynb) — one top-to-bottom
story (data → audit → exploration → baselines → controlled changes → search → frozen selection → test → error
analysis → inference), saved with outputs. It runs in a fresh Colab/Kaggle GPU session (`MODE="demo"`, ~15 min) or
retrains (`MODE="full"`).

## Results (test, evaluated once after a validation-only freeze)

| system | macro-F1 | accuracy | balanced acc. |
|---|---|---|---|
| majority class | 0.003 | 0.079 | 0.023 |
| E0 frozen ResNet-18 + linear head | 0.548 ± 0.009 | 0.607 | 0.541 |
| E1 fine-tune all layers | 0.653 ± 0.014 | 0.700 | 0.644 |
| E2 E1 + class-weighted loss | 0.662 ± 0.008 | 0.711 | 0.658 |
| E3 E1 + augmentation | 0.709 ± 0.005 | 0.751 | 0.702 |
| ConvNeXt-Tiny + aug, backbone LR 2e-4 (per seed) | 0.796 ± 0.005 | 0.832 | 0.791 |
| **final: 3-seed ensemble of the above** | **0.805** | **0.842** | **0.800** |

± = sd over seeds 0/1/2. Selection, search and pruning: [`docs/experiment_log.md`](docs/experiment_log.md).

## Layout

```
cw2/                 the pipeline (imported by notebook and scripts)
  data.py            Zenodo download + MD5, manifest, audit (exact + pHash duplicates), exclusion rule
  train.py           Config, in-memory image cache, GPU batch augmentation, models, training loop
  experiments.py     claim-queue sweep runner, validation-only selection, one-off test report
  metrics.py         macro-F1 / accuracy / balanced accuracy / per-class / confusion (fixed class order)
  inference.py       checkpoint loading (local or Hugging Face) and prediction from image files
  viz.py, report.py  figures and tables
scripts/             01_prepare_data → 02_sweep → 03_select → 04_test_report → 05_figures (06_hf_upload)
sweeps/              stage0–3 configuration specs, pruned.json
results/             committed outputs: data/ (manifest, exclusions, audit), runs/<config>_s<seed>/
                     (run.json, hist.csv, logits.npz), summary/ (selection.json, test_*.csv), figures/
notebooks/           the submission notebook (generated by tools/build_notebook.py, then executed)
docs/                experiment log
data/, outputs/      not committed: dataset, image caches, checkpoints (published on Hugging Face)
```

## Reproduce

```bash
pip install torch torchvision && pip install -r requirements.txt   # exact versions: requirements-lock.txt
python scripts/01_prepare_data.py      # download (1.06 GB) + MD5 + manifest/audit -> results/data/
python scripts/02_sweep.py             # all stages; start several copies to share one GPU
python scripts/03_select.py            # validation only; freezes results/summary/selection.json
python scripts/04_test_report.py       # test, once
python scripts/05_figures.py           # results/figures/
python tools/build_notebook.py && jupyter nbconvert --to notebook --execute --inplace notebooks/AIP304_CW2_Option1.ipynb
```

Seeds 0/1/2; checkpoint = epoch with best validation macro-F1; ImageNet weights from torchvision only.
Reported runs: 1× NVIDIA L4, torch 2.15.0 + CUDA 13.2, Python 3.12.
